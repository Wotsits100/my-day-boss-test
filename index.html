Backup & restore

Recommended: make a backup from time to time so precious recordings are not lost if the iPad is replaced, reset or its website data is cleared.

Restoring brings back diary entries, recordings, drawings, photos, videos and personalisation from a My Day backup file.

Privacy

Entries are stored locally in this browser/app. Deleting app/site data can remove them, so use backup if the memories matter long-term.
